📊 G-Sheets by AD

A modern, feature-rich spreadsheet application built with vanilla JavaScript that runs directly in your browser!

✨ Features
Core Functionality
📝 Multi-sheet support with tabbed interface
🔄 Undo/Redo functionality (Ctrl+Z, Ctrl+Y)
💾 Save and load spreadsheets
📤 Export to CSV format
🖱️ Drag and drop cells
Rich Cell Formatting
🎨 Text and background color customization
📊 Multiple font families and sizes
🔤 Text formatting (Bold, Italic, Underline)
⬅️ Text alignment options
📋 Cut, Copy, and Paste functionality
Advanced Features
🧮 Built-in Calculator
🧪 Formula Testing Interface
🕒 Multiple Clock Styles (Digital, Analog, Semi-Digital, Minimal)
🌙 Dark Mode Support
🎨 Multiple Theme Options:
Default
Light Blue
Dark Grey
Olive
Light Red
Accessibility & UX
🗣️ Speech synthesis for button tooltips
⌨️ Keyboard shortcuts
📱 Responsive design
⚡ Performance optimized
🔄 Auto-saving functionality
🚀 Getting Started
Clone the repository
Open index.html in your browser
Start creating spreadsheets!
🛠️ Technical Details
Built With
Pure JavaScript (No frameworks!)
HTML5
CSS3
Key Components
app.js - Core spreadsheet functionality
formula.js - Formula parsing and evaluation
database.js - Data persistence
styles.css - Styling and themes
💡 Usage
Create a new spreadsheet from the home page
Use the toolbar to format cells
Enter formulas starting with '=' in cells
Save your work using the 💾 button
Export to CSV using the 📤 button
🎨 Themes
Switch between different themes using the theme selector:

Default - Clean professional look
Light Blue - Calm and focused
Dark Grey - Easy on the eyes
Olive - Nature-inspired
Light Red - Energetic and bold
🤝 Contributing
Contributions, issues, and feature requests are welcome!
